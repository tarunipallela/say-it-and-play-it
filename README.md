# 🎮 Say It & Play It – Voice Controlled Game

A simple and fun **voice-controlled Dino game** built using **Python, Pygame, and Vosk (offline speech recognition)**.

You control the Dino using **voice commands only** — no keyboard needed!

---

## 🚀 Features

- 🦖 **Single Dino character** 
- 🌵 **One cactus obstacle**
- 🎤 Offline **voice control** using the Vosk model
- ⭐ Real-time **score display**
- 📢 Supported voice commands:
  - **"Start"** → Start the game
  - **"Jump"** → Make the Dino jump
  - **"Reset"** → Restart after game over
  - **"Exit"** → Quit the game

---

## 🛠️ Technologies Used

- **Python**
- **Pygame**
- **Vosk Speech Recognition**
- **Pyaudio / Sounddevice**
